# CONTEXT - 09.18 Body Composition Anthropometry V1

O piloto de bioimpedancia ja possui OCR, revisao, relatorio premium, IA, WhatsApp, Kommo e sync Actuar. A academia identificou que o percentual de gordura bruto da bioimpedancia esta inconsistente para uso principal. O Cordex precisa preservar os demais dados do exame, mas usar uma estimativa por medidas manuais como fonte oficial quando houver dados suficientes.

Esta fase nao substitui o modulo de avaliacao. Ela enriquece a Bioimpedancia v2 existente.

Decisao central: `body_fat_percent` vira legado/bruto/compatibilidade; `body_fat_used_percent` vira fonte oficial para produto.
