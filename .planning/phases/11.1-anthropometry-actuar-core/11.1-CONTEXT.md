# Phase 11.1 - Anthropometry Actuar Core

## Context

Phase 11.1 is the gate between local anthropometric assessment and any Actuar integration.

The approved plan requires a controlled Actuar spike before implementing sync. The spike must prove that the minimum anthropometric payload can be saved safely and that the created Actuar assessment id can be captured.

## Guardrails

- Do not implement Actuar sync until the spike passes.
- Do not send muscle mass for anthropometry.
- Do not invent muscle mass from lean mass.
- Do not use real credentials or a real student unless explicitly approved for the spike.
- Do not reuse the bioimpedance mapper as the anthropometric mapper.
- Local Spec 056 remains publishable even if this phase is blocked.

## Current branch result

Preflight ran on 2026-07-16 and produced a controlled NO-GO:

- no explicit Actuar credentials/session in this worktree;
- no designated test student;
- current successful historical payloads include `muscle_mass_kg`;
- current provider does not yet persist a created Actuar assessment id as the primary external assessment id.
