# Phase 11.1 - Plan

## Objective

Execute the Actuar Core spike for anthropometric assessments and decide go/no-go before implementation.

## Spike checklist

1. Confirm required fields in the real Actuar form.
2. Test whether muscle mass can remain empty.
3. Test whether date, weight, height and official body fat are sufficient.
4. Confirm whether Actuar differentiates physical assessment, anthropometry and bioimpedance.
5. Capture the created external assessment id.
6. Reopen history/report and confirm appearance.
7. Confirm duplicate detection.
8. Confirm save/update/close behavior.
9. Confirm timeout-after-click behavior.

## Result in this branch

Only preflight could run. Live Actuar execution is blocked until explicit credentials/session and a designated test student are provided.

## Implementation policy

No implementation of `assessment_push`, anthropometric Actuar jobs, retries, mapper, bridge payload or automatic sync is allowed while the spike is NO-GO.
